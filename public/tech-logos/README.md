# Technology marks

These SVG marks are bundled locally from the [Simple Icons project](https://github.com/simple-icons/simple-icons) under [CC0 1.0 Universal](https://github.com/simple-icons/simple-icons/blob/develop/LICENSE.md). The portfolio does not request them from a remote service at runtime.

React Native uses the React mark and Docker Compose uses the Docker mark. Azure, HTML / CSS, and REST APIs use text marks because there is no distinct logo that improves identification here.
